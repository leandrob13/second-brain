# Agent Instructions

When AI agents (like myself) are working in this repository or knowledge base, please adhere to the following rules:

- New files should not include white spaces in their names. (e.g., use hyphens or underscores).
- Each document needs to have reference links in order to validate the veracity of the information presented. Include active hyperlinks to those references if available, especially if the information was obtained from the web.
- When asked for research, agents may rely on their internal knowledge, but must also validate on the web to ensure the information still stands. If web research is performed, explicit hyperlinks to the external sources must be included.
